Process

How I work.

I don't start by opening a code editor. I start by understanding.

01

Understand

I begin by listening — to the problem, the users, and the goals. No assumptions. Understanding deeply before acting.

02

Explore

Research, competitive analysis, user journeys. I generate ideas and challenge them before committing to a direction.

03

Design

From rough wireframes to polished interfaces. I translate thinking into visuals — always with the user experience at the core.

04

Build

I develop the solution with clean, maintainable code. Responsive by default. Accessible from the start.

05

Improve

Shipping is not the end. I test, observe, and iterate — because good products grow over time.
